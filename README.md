## Stack
Frontend: HTML/CSS/JS (React) · Backend: Node + Express · DB: MongoDB Atlas · 360°: Pannellum

## Structure
/client  — frontend
/server  — Node + Express backend
/docs    — SRS, UML diagrams, project plan, notes

## Setup
1. Clone the repo
2. cd server && npm install
3. Create a .env file with MONGO_URI and JWT_SECRET
4. npm start
